# 更新记录

## 2026-10-28 — 本地网页与增量扫描

### 已完成

- 使用 `smart-vocab-quiz.py` 启动仅监听 `127.0.0.1` 的网页，并自动打开功能选择页。
- 首页提供“扫描词汇”和“生成试题”两个入口；试题页目前只预留界面，尚不生成题目。
- 扫描页支持从浏览器添加 PDF、扫描 `BookScan/` 中的新增文件、查看进度、搜索词汇及下载 JSON。
- PDF 内容的完整 SHA-256 用作扫描记录 ID。相同内容不会重复调用模型；逐图块缓存还能复用未变化的页面区域。
- 将已有词库和图块缓存登记到 `output/scan_manifest.json`，迁移时不重新识别旧 PDF。
- 页面右上角显示本地 AI 可用状态，支持重新检测；服务不可用时，首页两个入口弹出启动提示。
- 子页面顶部的“功能选择”使用与本机运行标识一致的胶囊样式，桌面和窄屏均可使用。
- 统一日志、配置文件、单元测试和运行文档已补齐。

### 数据与运行约定

- 本地 AI 由用户自行启动；项目只进行只读状态检查和识别请求，不管理服务进程。
- 真实 PDF、词库、扫描记录、图块缓存、日志及 `common.env` 不推送到 GitHub。
- 当词库在扫描记录建立后被手工修改，增量扫描会拒绝覆盖，以免丢失人工修订。
